# 我的 Omarchy 使用记录（2026-09）

在 [Omarchy](https://omarchy.org/)（基于 Arch + Hyprland）的 Linux 桌面环境日常使用过程中，陆续记录下来的笔记、踩坑修复与折腾总结。

每个主题单独放在一个子目录下。

## 目录

| 子目录 | 内容 |
|---|---|
| [`monitor/`](./monitor/) | 外接显示器时如何关闭笔记本自带屏幕 |
| [`chinese-input/`](./chinese-input/) | 在 Hyprland / Omarchy 下配置中文输入法 |
| [`hyprland-fix/`](./hyprland-fix/) | Hyprland 菜单触发黑屏的修复方案 |
| [`pacman-update/`](./pacman-update/) | pacman 镜像源配置与系统更新工作流 |
| [`waydroid-wxwork/`](./waydroid-wxwork/) | 在 Omarchy 上通过 Waydroid 运行企业微信（主文） |
| [`agent-usage/`](./agent-usage/) | Omarchy 顶部状态栏 AI Agent 面板集成 Antigravity 实时配额与自动化更新 |

## 说明

- 每篇文章独立成文，文中带有日期。
- 命令默认基于 Omarchy / Arch 体系；其他发行版请自行替换包名。
- `$USER` 为 shell 占位符，请替换为你自己的用户名。
